\# AI-Powered Tender Document Verification and Compliance System



\## Project Description



An AI-powered decision-support system for government procurement departments

to assist officers in verifying bidder-submitted tender documents and

checking compliance with tender requirements.



\## Technology Stack



\### Frontend

\- React

\- Vite

\- Bootstrap

\- Axios

\- React Router



\### Backend

\- Python

\- FastAPI

\- SQLAlchemy

\- Pydantic

\- JWT Authentication



\### Database

\- MySQL



\### AI/ML

\- OCR

\- NLP

\- Sentence Transformers

\- RAG

\- FAISS

\- Rule-based compliance engine
